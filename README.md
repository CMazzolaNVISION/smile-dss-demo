# SMILE DSS — interactive demo

**Live demo:** https://&lt;your-user&gt;.github.io/smile-dss-demo/

A static, browsable demo of the **SMILE Decision Support System (DSS)**, the clinician-facing web app of
the SMILE project. It shows what the DSS does: data exploration, game analytics and interpretable
machine-learning dashboards for adolescents' daily mood (ESM), serious-game play, questionnaires (PROMs)
and diaries.

> ⚠️ **Synthetic data only.** Every participant, answer, score and model result on this site was
> generated by a script. None of it comes from real people. Each page carries the banner
> *"Demo - synthetic data, not real participants"*.

## What you can do

1. Open the link above and pick one of three demo participants:

   | Participant | Country | Profile |
   |---|---|---|
   | Lena Demo | Belgium | mood improves over the six weeks; completed the whole game |
   | Marco Demo | Italy | lower mood, strong reactions to stressful events; completed the whole game |
   | Sofia Demo | Spain | stable, positive mood; plays the game very well |

2. Look at their data summary, then open the dashboards:

   | Dashboard | Badge | What it shows |
   |---|---|---|
   | Cohort Overview | – | the cohort across countries and demographics, with the participant highlighted; the cohort's game progress |
   | Game Performance | – | game progress, sublevel scores, mood before and after playing, NPC interactions |
   | Mood & PROMs | – | mood averages, sleep, day-by-day mood against a cohort reference, questionnaire sessions |
   | Game Analytics | ML | which modules go with a better change of mood, and which could be worth playing again |
   | ESM Analytics | Statistical model | how emotions relate to where the participant is, what they do and who they are with |
   | Mood Change Analytics | ML | what comes before feeling better or worse than usual: events, coping, the emotion network, an explainable model |

The pickers inside the dashboards (variable, module, mood) and the theme button (light, colorblind,
dark) work as in the real DSS.

**Not in the demo:** login, country and sequence selection, CSV downloads, the Mood & PROMs
reference-group choice (fixed to country + gender) and anything else that needs a server. These are
shown but disabled.

## How it is made

This repository contains only the **generated website**: plain HTML, the Plotly.js library, map
outlines and images. It contains no DSS source code and no real data.

The pages are produced by a "freezer" script (`demo/build_demo.py`) in the DSS's own repository. The
script:

1. generates a synthetic cohort in the same structure as the study data: 3 demo participants with
   6 weeks of data each, plus a background cohort;
2. builds the cohort tables and trains the DSS's models on that synthetic cohort;
3. runs the real DSS code and saves every page, for every participant, option and theme, as static
   HTML.

So the pages look exactly like the real DSS, but nothing on them refers to a real person.


## Updating the site

Do not edit the HTML by hand: every build overwrites it (this README is kept). From the DSS
repository:

```bash
python demo/build_demo.py          # or --skip-data to re-render the pages only
cd demo/site
git add -A
git commit -m "Update demo"
git push
```

## Layout

```
index.html                 redirects to the participant picker in the last theme used
light/ dark/ colorblind/   one copy of the site per theme
  index.html               participant picker
  <participant>/           summary, home and every dashboard page
static/                    images, plotly.min.js, map outlines (topojson)
.nojekyll                  serve files as they are
```

## About SMILE

The SMILE project develops digital tools to support adolescents' mental health: an experience-sampling
app, a serious game and this decision support system for clinicians. The project is funded by the
European Union under Horizon Europe Programme GA No 101080923.

*This demo is for illustration only. It is not a medical device and must not be used for clinical
decisions.*
